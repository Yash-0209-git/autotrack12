# AutoTrack

Professional vehicle service management system.

## Project info

AutoTrack helps manage vehicle services, maintenance schedules, and customer records efficiently.

## How can I run this project locally?

### Requirements
- Node.js & npm installed - [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating)

### Steps

```sh
# Step 1: Clone the repository
git clone https://github.com/Yash-0209-git/autotrack12.git

# Step 2: Navigate to the project directory
cd autotrack12

# Step 3: Install dependencies
npm install

# Step 4: Start the development server
npm run dev
```
